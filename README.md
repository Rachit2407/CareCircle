# CareCircle AI 🎙️👵

**Voice-first AI Care Coordination Assistant for Families**

Built for the **Amazon Alexa+ Track**.

CareCircle AI connects families caring for elderly loved ones through natural voice interaction and a centralized live dashboard. Powered by a self-hosted Model Context Protocol (MCP) server, autonomous agentic workflows, and proactive coordination tools.

## 🚀 Key Features

1. **Voice-First Coordination:** Hands-free logging of vitals, medications, and observations via Alexa+ or the web simulator.
2. **Centralized Family Dashboard:** Shared visibility into completed vs. pending tasks, elimination of the caregiver "bystander effect".
3. **Agentic Health Memory & Escalation:** Cross-session tracking connecting symptoms to medications and automated overdue task alerts.
4. **Evidence-Based Summaries:** Automatic synthesis of caregiver logs into structured summaries for doctor appointments.
